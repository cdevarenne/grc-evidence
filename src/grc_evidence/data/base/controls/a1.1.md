# Intent

Workloads declare the capacity they need and how to tell they are healthy,
so the platform can plan for them and replace a failed instance.

# NIST SP 800-53 mapping

- **CP-2(2)** — Contingency Plan: Capacity Planning
- **SC-6** — Resource Availability

# Scope

Only declared configuration is checked. Capacity monitoring, recovery, and
backups (the rest of SOC 2 A1) are not evidenced by any scanner here.
